# VibeLab Unity-1 Android Gradle Project

This repository contains Android Gradle project files prepared for a VibeLab Unity app submission.

VibeLab app type should remain `UNITY` (`app_type=3`) even though the repository content is an Android Gradle project.

## Package

```text
com.example.vibelab.unity1
```

## Notes

- This repository is not a raw Unity project and does not contain an APK.
- `unityProjectPath` and `unity.projectPath` are intentionally empty.
- `local.properties`, signing keys, tokens, and APK artifacts must not be committed.
- Unity export, IL2CPP precompile, and local Unity final verification were not run on this machine because no local Unity build environment is available.
